# e2e 控件坐标速查（已实测校验）

本文记录 PocketCOM 桌面宿主（960×640 视口）全部可交互控件的**点击坐标**，供
`--click`/`--mouse`/`--wheel` 脚本化 e2e 直接查表使用。所有坐标均为**画布逻辑
像素**（坐标系定义见 [e2e.md](e2e.md)）；除注明"公式推导"外，全部经本机真机
运行逐一点击 + 截图 diff/trace 校验（2026-09，commit 1e1b519，zh-CN 默认布局）。

改布局（`app/panel.tsx` layoutInfo、`app/layout.ts`、`app/transfer.tsx`、widgets
几何常量）后须重测：复验配方见文末。

## 2. 下拉弹层项坐标

弹层几何（`app/widgets.tsx` PopupBox）：项高 26、内边距 4、与控制框间距 4；
**优先开在控制框下方**（popupTop = 控制框底 + 4），若超高（> 612）**翻转到
上方**（popupTop = 控制框顶 − 4 − 盒高）；盒高 = min(项数, 10) × 26 + 8
（超 10 项内部滚动，滚轮在弹层上滚动）。

**项 i 的点击坐标 = (弹层 x 中心, popupTop + 17 + 26·i)。**

| 弹层 | popupTop | 各项中心 y（自上而下） | 校验 |

## 7. 其他连接类型的参数块

布局表（`panel.tsx` layoutInfo）随连接类型伸缩。公式：**字段块控件中心 =
块顶 + 81**（y），半宽左列 x=72、右列 x=200，全宽 x=136；**勾选框中心 =
块顶 + 60**、x=19。各类型块顶（自 `put` 序列推导，MCP 关）：

| 类型 | 参数块（块顶 → 点击坐标） |
|---|---|
| TCP Client | host 68 → **(136,149)**；端口 126 → **(136,207)**；自动重连 186 → **(19,246)**；重连间隔 212 → **(136,279)**（勾选自动重连后出现） |
| TCP Server | 监听端口 68 → **(136,149)**；客户端行 i（i 从 0）：地址文字 + **踢除 Btn (234, 187+24i)**（框 208..260 × 177+24i..197+24i）；有 n 个客户端时 mode 及以下整体下移 24n |
| UDP | 目标主机 68 → **(136,149)**；本地端口 126 → **(72,207)**；远端端口 126 → **(200,207)** |
| WebSocket | URL 68 → **(136,149)**；子协议 126 → **(136,207)**；自动重连 184 → **(19,244)**；重连间隔 210 → **(136,277)** |
| 回环 | 无参数块；mode 上移至块顶 81 → 收发 **(74,162)** / 终端 **(198,162)** |
| （通用） | mode/div 之后（MCP、语言、主题…）的相对位置同串口布局；mode 块顶：serial 351 · tcp 237 · ws 235 · udp 199 · tcps 141+24n · loopback 81 |

TCP Server 定向发送 Select（连接且 ≥1 客户端时）：与历史 Select 同一锚点
公式（`sendOptSelectX`，定向在前、历史随其后 +158）；zh 无历史时定向控件约
587..737 → **(662, 529)**（公式推导，需 tcps 连接态，未单独 e2e）。

## 9. 终端模式区域

终端模式替换右侧收发+发送两区（面板不动）。网格原点 **(280, 6)**
（`TERM_PAD_X=8, TERM_PAD_Y=6`），行高随字号档 16/18/21（12/14/16px）。
无按钮；交互区域：字符网格点击/拖拽选区（`--mouse d/m/u`）、滚轮回滚
（`--wheel`，x ≥ 272）、键盘直发（`--key`/`--type`）、Ctrl 控制码
（`--key ctl+c` 等）。配方见 [e2e.md](e2e.md) M3 节。

## 10. 日志窗行几何（读断言定位用）

- 行高 `LINE_H`：12px→16 · **14px（默认）→18** · 16px→21。
- 第 i 行文本区：y = 35 + i·行高，文字从 x = 288（280+8 padding）起。
- 空态提示（"暂无数据"）居中于 (616, ≈270)——首条日志出现后消失
  （diff 断言时注意这处额外变化）。

## 11. 已知坑（diff/点击断相关）

1. **默认主题 = 深色**（`theme.ts` themeMode 初值 "dark"）：点"深色"项无视觉
   变化，diff 断言会 IDENTICAL——验证主题弹层请点"浅色"。
2. **弹层遮罩 `#00000001`**：弹层打开的全屏遮罩使截图出现 ±1 全屏像素噪声，
   字节级 diff 必须带容差（≥2/255）。
3. **maxScroll 理论 vs 实测差 3px**（226→223、342→339）：以截图实测为准；
   滚动量给足（−226/−400）靠钳制到底即可，勿依赖精确值。
4. **导出/导入按钮弹原生面板**（保存/打开对话框），脚本 e2e 会卡住，勿盲点；
   坐标仅列出备查。
5. **历史/定向下拉弹层曾与控件脱节**（§6/§7）：弹层 x 曾固定 380、控件实际
   在行尾——2026-09 已修复（`app/sendlayout.ts` 按流式标签宽累计锚点，zh/en
   双语 e2e 验证贴合）；改选项行结构/文案时跑 `test/app/sendlayout.test.ts`
   并按 §12 复验。
6. **en 布局勾选框 x 平移**（§5/§6 表）；y 全部不变。MCP e2e 用
   `language:"en"` 时以 en 列为准。
7. 点击配方一律 `--mouse X,Y@T-2 --click X,Y@T`（先 hover 聚焦），交互后
   截图留 2–3 tick 余量。

## 12. 复验配方

坐标随布局表变，重验流程（工具 `tools/coords-probe.py`）：

```bash
# ① 基线（重置 config，避免 lastConn 预填污染）
mkdir -p /tmp/pcom && echo '{}' > /tmp/pcom/config.json
POCKETCOM_CONFIG=/tmp/pcom/config.json node tools/dev.mjs \
  -- --screenshot /tmp/pcom/base.png@90 --quit-after 100

# ② 点击目标 + 截图
POCKETCOM_CONFIG=/tmp/pcom/config.json node tools/dev.mjs \
  -- --mouse 136,91@58 --click 136,91@60 \
     --screenshot /tmp/pcom/shot.png@64 --quit-after 68

# ③ diff：变化区域应精确落在预期控件矩形上（容差 10，滤掉弹层遮罩噪声）
python3 tools/coords-probe.py diff /tmp/pcom/base.png /tmp/pcom/shot.png
# → {'bbox': (12, 77, 259, 272), ...}  # 控制框高亮 + 弹层，即命中

# 辅助：采样某坐标颜色 / 找 accent（激活分段、选中勾选框、主按钮）
python3 tools/coords-probe.py sample shot.png 136 91
python3 tools/coords-probe.py accent shot.png
```

断言语义补充：副作用可用 `POCKETCOM_TRACE=1` 抓 `com.*` 调用
（mcpStart/mcpStop/cfgWrite/serialList…）与 `svc <- {"t":"copy"}` 行；
同一 UI 状态两次运行截图**字节一致**（无交互时 diff 必为 IDENTICAL，可作
负对照）。

— 校验记录：39 组真机运行（弹层 7 + 勾选/分段/按钮 12 + 滚动/设置区 5 +
MCP 4 + 终端 2 + 历史 3 + 布局基线若干），坐标均由截图像素级确认；
`✓` 标记表示该坐标经过点击→效果闭环验证。
