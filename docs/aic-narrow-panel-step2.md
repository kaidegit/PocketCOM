## 最终改动与边界

同一套共享 App 在视口宽度小于 720px 时，默认不创建连接配置面板，顶部用 32px 操作栏打开配置抽屉，工作区使用全宽。抽屉复用 `LeftPanel`，宽 272px，通过 Portal 和显式视口尺寸遮罩显示；返回、点遮罩或 Escape 收起。内容区支持手指纵向拖动，并保留上翻/下翻按钮访问短屏中的配置项。宽屏布局保持原来的左右分栏。

**首次打开才创建，关闭后移出视口，后续复用同一个实例。** 面板首次创建后的内存不会因关闭而全部退回启动基线。本步主要收益是首次打开配置前的启动工作集，不能声称所有运行状态都减少 30.7%。切回宽屏时卸载窄屏实例，释放滚轮订阅和字段句柄。

起初验证过关闭即卸载：有显式 GC 的 200 次开关能完成，但历史峰值为 7,013,211 bytes；快速开关、不额外触发 GC、限制 caps 为 7 MiB 时失败。因此交付版本采用首次创建后复用，以避免重建峰值；失败方案的原始证据仍保留，不作为交付结果。生产 GC 策略没有改变，也没有从 App 主动调用 GC。

工作区、发送草稿、会话和日志/终端模型不随抽屉开关卸载。关闭配置时提交未按 Enter 的字段文字并清除活跃输入域；打开应用配置先收起连接抽屉。布局几何同时用于收发区、终端、选区及滚轮路由；发送输入宽度改为由可用工作区显式计算。隐藏配置字段不参与工作区选区命中。

本步先更新 SPEC §3.1，再实现；不调整 JSON profile、容量、字体选择、堆/栈、设备桥或 allocator。高级收发工具栏在 480px 下仍有溢出，后续另做折叠；当前 AIC 无 `com.*` 桥，实际显示共享空态。本步不代表完整窄屏产品 UI、板端收发或软键盘已验收。

## 关闭后无法重开修复（2026-10-24）

用户报告 AIC 连接配置第一次打开正常，关闭后再次点击没有反应。根因在 PocketJS 的
`framework/src/components-vue-vapor.ts:createPortalRoot()`：透明的 480×272 Portal host
未设置 `hitPass: 1`。抽屉内容关闭后移到视口外，但 host 仍覆盖屏幕。桌面鼠标使用 ink 命中，
能穿过这个未绘制的容器；AIC 触摸使用 bounds 命中，先命中 host，再因它没有可激活的祖先而丢弃点击。

修复只给 Vue Vapor Portal host 补上 `hitPass: 1`，与 Solid Portal、Vue Vapor 辅助屏 Portal
一致；host 自身不拦截命中，内容和遮罩仍照常阻挡/响应触摸。保持 SPEC §3.1 的延后创建与实例复用，
不更改应用开关逻辑、产品 feature、容量、堆/栈、GE 或生产 GC 策略。
