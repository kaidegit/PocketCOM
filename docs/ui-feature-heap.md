# ui.* 编译期裁剪与内存对比

测量时间：2026-10-22 23:59（Asia/Shanghai）。

九项 UI feature 已接入裁剪，平台与实验开关只读取 `pocket.features.json`；host 指本项目 macOS 的 `desktop` profile。正式 AIC 入口仍是诊断页。本次没有构建或烧录固件。

## 裁剪范围

- 选区：日志、终端、TextField 的选区 ref、拖动路由、命中区注册、越界自动滚动及高亮；关闭时保留普通输入、编辑键、光标和滚轮。`app/textsel.ts` 声明为专属模块并从关闭组收据剔除。
- 剪贴板、菜单、快捷键：裁剪复制/粘贴路由、MCP 复制按钮、右键菜单与文案、Cmd/Ctrl+Enter 发送及 Shift+PageUp/PageDown 本地翻页。终端协议按键保持可用。右键菜单依赖选区；不依赖剪贴板，可独立保留全选。
- 语言：裁剪切换控件、草稿状态、watcher、`app/locale.ts` 及英文包，固定 zh-CN。
- 主题：裁剪切换控件、草稿状态、watcher、浅色令牌；固定深色。系统主题依赖主题切换，关闭时不创建外观 ref、不处理 appearance 更新，system 配置按深色处理。
- 字号：裁剪设置控件、草稿状态和切换 watcher，固定 14px。字体槽等共享度量契约保留。
- 语言/主题/字号关闭后，配置加载、导入和 MCP 写入均不激活对应设置；配置导出仍保留原字段。设置弹窗收拢被裁剪的行，命中区和滚动高度同步。
- 软键盘：补齐 `app/soft-keyboard.tsx`，主界面文本域聚焦后可由状态栏展开，支持字母大小写、数字、常用符号、空格、退格、回车及收起。按键复用活跃文本域协议并保留焦点；关闭组剔除整个模块、状态、入口与文案。

## 实验条件

```sh
npm run probe:features -- --feature ui
```

`ui-on` / `ui-off` 仅改变 UI 开关，terminal/MCP/传输和容量相同。两组使用同一共享 App、AIC plan、480×272、MiSans/JetBrains Mono、JS 配额 5 MiB；caps 不注入预算。每组独立进程三次、每次 120 turns，以下取各阶段中位数。六次探针均完成，分配失败与错误帧为零。

默认串口面板可见，没有 com 桥，右侧为桥不可用空态；没有聚焦输入域、打开设置、展开软键盘或挂载终端网格，没有收发与历史增长。本实验量的是编译代码、字体资源和空闲状态，交互时新增的选择/软键盘节点不在读数内。构建检查专属模块收据，QuickJS 入口断言固定语言/主题/字号及系统主题状态不分配。

## 结果

单位为 bytes；caps 包括 QuickJS、Rust UI 和分配包装头。

| 指标 | UI 全开 | UI 全关 | 减少 | 降幅 |
|---|---:|---:|---:|---:|
| S2 资源常驻 | 787,925 | 746,513 | 41,412 | 5.26% |
| S3 编译峰值 | 5,160,132 | 4,904,905 | 255,227 | 4.95% |
| S4 挂载常驻 | 7,232,110 | 6,944,562 | 287,548 | 3.98% |
| S5 稳态 caps | 7,375,661 | 7,088,017 | 287,644 | 3.90% |
| 全过程 caps 峰值 | 8,153,362 | 7,850,748 | 302,614 | 3.71% |
| S5 QuickJS malloc_size | 3,947,800 | 3,789,872 | 157,928 | 4.00% |
| 压缩 JS | 289,455 | 276,053 | 13,402 | 4.63% |
| PAK | 597,072 | 555,664 | 41,408 | 6.94% |

稳态减少 **280.9 KiB（3.90%）**，全过程峰值减少 **295.5 KiB（3.71%）**。关闭组峰值仍为 **7.49 MiB**，尚不足以据此恢复板端完整 App。

探针使用 64 位 malloc，不模拟 TLSF 碎片，也不包括 RT-Thread 任务栈和 WiFi/lwIP 系统占用。此结果用于离板裁剪比较，板端是否可用须以 WiFi 不同状态下的真实峰值/稳态验收。
