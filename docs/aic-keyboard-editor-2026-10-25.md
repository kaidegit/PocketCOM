# AIC 软键盘临时编辑面板（2026-10-25）

用户确认采用临时编辑面板，解决键盘展开后原输入框被遮挡的问题，同时要求键帽文字居中。
本记录承接 [二次点击键盘修复](aic-soft-keyboard-2026-10-25.md)，旧快照保持不变。

## 行为

480×272 下，从上到下为字段名称 24px、编辑区 56px、键盘 164px、状态栏 28px。
发送内容、自定义波特率、连接参数和设置字段均显示各自名称；字符键、数字键和功能键
统一 `textAlign: Center`，28px 行高使字形按引擎行盒垂直居中。MiSans 键帽与 JetBrains Mono 输入内容保持各自字体槽。

临时面板直接使用原 TextField 的文本和光标，没有第二份草稿，也没有确认保存步骤。
长行水平跟随光标、多行显示光标附近两行；触摸或鼠标点击可见文本可以移动原域光标。
收起回到原界面，内容和光标位置保留；回车遵循原域语义（发送框换行，单行参数调用原提交），
发送仍使用原发送按钮。首次点击聚焦、再次点击展开的规则不变。

面板和键盘首次使用创建、之后隐藏复用。鼠标门控扩展到整个编辑面板，避免点预览时
选中背后的接收区或配置字段。键盘仍位于抽屉/设置之上；收起后恢复底层命中。
不改变 JSON 中其他 feature、JS 配额、系统堆或缓存容量。

## 接口与实现

`app/fields.ts` 增加可选 `FieldEditor` 访问接口，提供字段名称、显示文本、光标、字号和移动光标操作；
由原 TextField 实现，既有虚拟/测试域仍可不提供。
`app/keyboard-editor.tsx` 只渲染此实时状态，`keyboard-editor-layout.ts` 输出两行有界窗口及点击到原文索引的映射。
两模块与现有键盘统一归属 `ui.soft-keyboard`，关闭时连同文案裁剪；不依赖已被 AIC 裁剪的 `ui.selection` 模块。

- 类型检查、全仓库 340 项测试、桌面 check/build、AIC check/package/build 通过。
- 新增布局测试覆盖空文本、开头/结尾换行、两行窗口、长行与点击索引。
- 真实共享 App + Vue Vapor/core WASM 测试覆盖发送、参数、设置字段；实时标题/内容/光标、
  触摸与 companion 鼠标点击预览、1000 字符长行、回车、多轮开关、大小写、关闭后光标保留及功能关闭裁剪。
  WASM harness 无字体 atlas，仅提供固定字宽用于几何断言；实际包另以真实字体验证。
- 实际交付包经 native QuickJS/core 的 240 turns 测试：第一次点击不展开，第二次展开，输入 q，
  点击预览开头再输入 z，原域与预览均变为 zq；反复开关与设置字段编辑均通过逐轮状态断言。
  240 正常帧、0 帧错误、0 caps 分配失败。
- 使用实际包/字体/native RGB565 renderer 生成 focused、open、typed-preview、typed-closed 四张图并目视检查，
  确认键帽居中、编辑区文本/光标可见，收起后原框保留 q。

离板口径仍为 64 位 malloc，不模拟 RT-Thread/TLSF、真实串口负载或 WiFi，且注入 com mock 和诊断记录。
默认无 com 桥的 120 turns 对照：caps 存活 3,871,483 B、峰值 4,915,701 B。
含发送、键盘、抽屉及设置的 240 turns：caps 存活 9,379,841 B、峰值 9,496,621 B；
末帧 JS malloc_size 5,057,820 / 5,242,880 B。没有增加配额或手动 GC。
这些组合读数较高，**不能证明板端 7 MiB SW 堆有足够余量**；真机峰值与实际输入发送仍待用户烧录复验。
